# Betty Zhang portfolio

Static site for GitHub Pages. No build step.

```
index.html          Portfolio (home page)
soulie/index.html   Soulie case study  ->  /soulie/
assets/             Images and the resume PDF
```

## Common updates

- **New resume:** replace `assets/Yi-Zhang-Resume.pdf` (keep the same file name).
- **New image:** put it in `assets/`, then copy an existing `<img>` tag and change the `src` and `alt`.
- **Publish a change:** `git add . && git commit -m "Update site" && git push`
